## 📋 讨论背景

用户提出想法:
> 每个子 agent 在自己的项目里操作,使用 harness 管理,但是 harness 管理里面有五个阶段,然后会生成我们的四件套,里面的 feature 会更加颗粒化。但是如果这样做,就会有个问题,前面的研究设计阶段需要大量资料,这是卡点。

---

## ✅ 教练的判断

**思路本身 = 一流团队的"Fractal Agent Architecture"(分形 Agent 架构)。**

**优点 4 条:**
1. 🎯 分形结构 — 主控用 harness,子项目也用 harness,统一心智模型
2. 📦 自治闭环 — 每个子 agent 自己研究/规划/构建/复盘/调试,不用主控喂饭
3. 🔬 颗粒化 — 主控的 S0-18 拆成子项目的 S0-18-1/2/3/4,粒度刚好
4. 🔁 可复用 — 同一套 4 件套模板,5 个子项目都能套

**卡点 1 条(用户已识别):**
- 🔥 研究阶段需要大量资料 → 子 agent context 爆炸 + token 烧光 + 易出错

---

## 💡 候选方案 4 个 (组合使用)

### 🥇 解药 1 · 预消化便当法 (最推荐 · 必做)

**核心:** 主控把"研究阶段"提前做完,给子 agent 一个**便当盒**,而不是让它自己去菜市场。

**主控产出 3 种便当:**
| 便当 | 内容 | 大小 |
|------|------|------|
| 🍱 task-brief.md | 这个任务要做啥 | < 1KB |
| 🍱 context-pack.md | 必读的契约+规则 | < 10KB |
| 🍱 reference-links.md | 想深挖时再看的指针 | 链接列表 |

**位置:** `master/briefs/S0-XX-xxx.md`

---

### 🥈 解药 2 · L3-v4 改 L3-v4-Lite

**核心:** 子 agent 的 5 阶段砍掉"研究阶段",只剩 4 阶段(规划/构建/复盘/调试)。

**理由:** 研究已被主控外包,子 agent 直接从规划开始。

---

### 🥉 解药 3 · RAG 检索 + 索引

**核心:** 给 `knowlage/` 写 `INDEX.md`,子 agent 按需精准检索,不全读。

**主控工作量:** 写一次 INDEX,所有子 agent 受益。

---

### 🏅 解药 4 · 二级 Agent 拆分

**核心:** 把"研究"独立成短命子 agent,消化完就退场,释放 context。

**适用:** 边缘任务,主控没预消化的内容。

---

## 📊 效果对比 (估算)

| 指标 | 原想法 | 加 4 解药 |
|------|--------|----------|
| 子 agent 启动时间 | 30-60 分钟 | 2-5 分钟 |
| Context 占用 | 200K+ tokens | 15-30K |
| token 成本 | 高 | 降 80-90% |
| 出错率 | 中(自己消化易偏) | 低(主控已校准) |
| 主控工作量 | 低 | 中(前期投入,后期省) |

---

## 🎯 教练建议的组合拳

```
🥇 解药 1 (预消化) → 必做,主控产出 briefs/
       +
🥈 解药 2 (Lite 版) → 子项目 harness 配置改
       +
🥉 解药 3 (索引)   → knowlage/INDEX.md 写一次
       +
🏅 解药 4 (二级)   → 遇到必须深挖才用
```

---

## 🔑 铁律

> **主控的核心价值 = 把知识库压缩成 brief。**
> **子 agent 的核心价值 = 把 brief 变成代码。**

## ✅ 6 个未决问题拍板结果 (2026-06-07)

| Q | 问题 | 最终决策 |
|---|------|---------|
| Q1 | brief 模板字段 | **升级到 9 字段** (加 依赖任务/估算工时/失败回滚) |
| Q2 | 一次性写 37 个还是现写? | **C · 分 3 批写** (关键 7 + 主链 15 + 辅助 15) |
| Q3 | brief 写错怎么办? | **子 agent 只能反馈不能改** (报 BRIEF_ERROR, 主控仲裁) |
| Q4 | L3-v4-Lite 调试回流? | **双轨 + 3 级标签** (INFO/WARN/CRITICAL/EMERGENCY) |
| Q5 | INDEX.md 谁维护? | **主控独占** (子 agent 只能"建议"不能"改") |
| Q6 | 二级 agent 用 isolation 还是 spawn? | **默认 spawn, 并行才 isolation** (90% 用 spawn) |
