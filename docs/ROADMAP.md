## 🎩 主控阶段心法

主控用 `/harness-l3-v4` 走 5 阶段, 每阶段主控 vs 子 agent 分工:

| 阶段 | 主控做 | 子 agent 做 |
|------|--------|------------|
| **研究** | 读 knowlage/, 写 brief | (不参与) |
| **规划** | 写 ADR + feature_list | 读 brief, 出小计划 |
| **构建** | 看 progress, 不写代码 | 按 brief 写代码 |
| **复盘** | 跑 contract-lint, 仲裁 | 跑 unit test, 报告问题 |
| **调试** | 解跨子项目冲突 | 修 bug, 回流问题给主控 |

**主控铁律:** 主控的核心价值 = 把知识库压缩成 brief。子 agent 的核心价值 = 把 brief 变成代码。
