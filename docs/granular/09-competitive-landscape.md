## 2. 主控的差异化定位

主控复刻云笔, 同时在以下维度**超越**云笔:

| 维度 | 云笔现状 | 主控改进 |
|------|----------|----------|
| **蒸馏管线** | 仅基础摘要 | 3 阶段 (Generator → Extractor → Checker) + 自动建议 |
| **一致性维护** | 手动 | 5 层自动校验 + Cron 任务 |
| **跨模块联动** | 部分 | 完整事件总线 |
| **设定变更传播** | 手动刷新 | 自动广播 |
| **AI 厂商** | 12 家但锁定 | 12 家 + BYOK, 完全开放 |
| **本地模型** | 基础 | Ollama / LM Studio / vLLM 全支持 |
| **长文本上下文** | 简单滚动 | 3 层 (系统/项目/当前), 智能压缩 |
| **导出** | Markdown | + Docx / PDF / EPUB |
